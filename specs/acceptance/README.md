# V2 Acceptance Gate Artifacts

This directory contains the reusable acceptance standard and evidence templates required before future V2 business packages may claim capability coverage.

These artifacts are governance infrastructure only. They do not authorize business implementation, application behavior changes, UI changes, database changes, migrations, or test-suite changes.

Required use for future V2 packages:

- Start from [package_acceptance_standard.md](package_acceptance_standard.md).
- Record capability evidence in [capability_evidence_ledger_template.md](capability_evidence_ledger_template.md).
- Record route, UI, test, unmapped, and completion evidence using [evidence_templates.md](evidence_templates.md) and [package_completion_report_template.md](package_completion_report_template.md).
- Keep source evidence, runtime evidence, UI evidence, and test evidence separate.
- Do not use documentation alone as positive implementation evidence.
- Do not claim package completion while unexplained business or runtime items remain `UNMAPPED`.
