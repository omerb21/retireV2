## Purpose

This matrix maps the V1 capability surface identified in repository reference evidence to the current V2 implementation and planning state. V1 evidence is reference evidence only. It does not authorize V2 implementation.

Status values:

- EXISTS: V2 evidence shows the capability is implemented and accepted for current V2 scope.
- PARTIAL: V2 evidence shows a bounded subset exists, with remaining scope absent, excluded, or requiring later authority.
- MISSING: V1 capability is not found in V2 evidence and is not explicitly excluded.
- EXCLUDED: V2 planning evidence says this capability is outside the current approved V2 scope.
- NEEDS_DECISION: V2 planning evidence requires a later product/scope decision before implementation planning.
- UNKNOWN: Evidence is insufficient to classify the capability safely.
