## 1. Current Truth Statement

The current Master Sequence, Mechanical Parity Ledger, Full Gap Register, and Full Plan Coverage Proof are control documents. They provide internal mapping coverage, but they do not externally prove that every required capability was included from the beginning.

This Required Capability Universe defines the external requirement list against which future coverage must be tested. It does not prove that the plan is complete, does not prove V1 parity, and does not authorize implementation. Planning documents are never implementation evidence. 02M remains frozen.

## 2. Requirement Source Model

| Source type | Meaning |
|---|---|
| `V1_EVIDENCE` | Requirement derived from the read-only V1 source-verified map, audit, runtime addendum, routes, or collected/runtime test evidence. |
| `MASTER_SEQUENCE` | Requirement represented by an M01-M16 milestone contract. |
| `PARITY_LEDGER` | Requirement mapped to one or more mechanical V1/V2 evidence rows. |
| `GAP_REGISTER` | Requirement mapped to one or more known partial, missing, replacement-review, or inspection gaps. |
| `PROFESSIONAL_DOMAIN` | Requirement needed to challenge professional Israeli retirement-planning completeness even when repository evidence is incomplete. |
| `NEGATIVE_CHALLENGE` | Requirement added or tagged because a named challenge previously exposed a possible planning hole. |

A requirement may use multiple source types. Source type establishes why the requirement belongs in the universe; it does not authorize implementation.

## 3. Requirement Status Definitions

| Status | Definition |
|---|---|
| `REQ_MAPPED_VERIFIED` | The requirement maps to a verified V2 ledger row. |
| `REQ_MAPPED_GAP` | The requirement maps to one or more non-unknown gap rows. |
| `REQ_MAPPED_UNKNOWN` | The requirement maps to one or more `UNKNOWN_NEEDS_INSPECTION` ledger rows. |
| `REQ_UNMAPPED` | The requirement is required but no current Master/Ledger/Gap control mapping proves coverage. |
| `REQ_NEEDS_DOMAIN_DECISION` | Professional applicability or legal/business scope must be decided before implementation authority can exist. |
| `REQ_DUPLICATE_OF` | Use only when another Requirement ID fully represents the same requirement; no row currently uses this status. |
